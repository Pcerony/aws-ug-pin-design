# 徽章外轮廓工作台

入口：`badge-dimensions.html`。静态页面，可直接用浏览器打开，不需要安装依赖或启动服务。

本页是新的尺寸讨论工具，不覆盖历史设计、贴图或3D模型。初始值不是已经确认的尺寸，锁定按钮仅锁定浏览器中的草案，不代表生产审核完成。

## 名义母版

单位全部为毫米，坐标代表金属最外轮廓，不是内部珐琅区。

| 参数 | 初始值 | 含义 |
| --- | --- | --- |
| W | 50 | 山墙墙顶宽度 |
| H | 50 | 墙身高度 |
| R | 30 | 山墙尖顶高度 |
| D | 30 | 侧墙上边宽度 / 房屋进深 |
| T | 0 | 仅山墙每侧底边收窄量 |
| G | 2 | 12展开时的中央连接区宽度 |
| 厚度 | 各1 | 前墙、后墙、左墙、右墙、屋顶分别可调0到20毫米 |
| E | 0 | 前后每端屋顶外延，独立于墙厚补偿，0到50毫米 |
| L | 0 | 左右每侧屋顶水平外延，沿现有坡面延长，0到50毫米 |
| A | 0° | 前后墙共用外倾角，0到45°，以底边基准线为轴 |
| I | 0 | 左右侧墙各自距山墙最外侧的水平内凹距离 |

2026-10-07调整：默认山墙宽50、总高80毫米。宽度、墙身高度、侧墙上宽上限150毫米，尖顶高度上限100毫米，连接区上限20毫米。保留浏览器中已有草案，使用“恢复初始值”可应用新的讨论起点；进深30毫米暂未改动。

- 1与6：共用五边形，总宽W，总高H+R，底边W-2T。
- 3与9：0°时为垂直矩形D×Hs；前后墙外倾时两端加入三角补片，成为六边形，总宽D+2Hs·sinA、总高Hs，底边D不变。Hs=H+2RI/W；T不作用于侧墙。
- 12：两片等大矩形，基准单片斜长S0=sqrt((W/2)^2+R^2)，含左右外延的斜长S=S0×(1+2L/W)，进深Dr=D+2(H+R)sinA+(前墙厚度+后墙厚度)cosA+2E；展开总宽2S+G。屋顶厚度沿坡面向外单位法线测量，每半片为直角矩形厚板。SVG虚线标出外延前的矩形边界。
- 坡度：atan2(R,W/2)。

轮廓和厚度均为名义尺寸，未加入圆角、倒角、装配公差、磁吸或铰链实体。I小于T时，山墙与侧墙之间仍产生三角空隙，3D预览将其标红，不应直接送厂。侧墙上沿基准边贴合屋顶，但向内加厚后顶部仍平切，未自动生成内侧斜切面。

## 文件与状态

- `assets/js/badge-dimensions-geometry.js`：统一参数校验、轮廓坐标、派生尺寸与毫米SVG导出。
- `tests/badge-dimensions.test.cjs`：母版同步、屋顶推导、收窄量、输入校验及导出格式测试。
- `assets/js/badge-dimensions-viewer.js`：本地Three.js与OrbitControls驱动的3D预览，含旋转、缩放、面板分解、屋顶与编号开关、重置视角。
- 浏览器在本地保存当前参数和锁定状态，存储键为`aws-badge-outline-draft-v01`。
- 导出规格是JSON，含参数、派生尺寸、五枚坐标与`productionReady: false`。
- V0.10支持导入V0.1到V0.10规格，重新校验并推导坐标、高度及屋顶进深。旧版本缺少厚度时补为1毫米，缺少I的V0.1/V0.2补为0；旧规格保留已有参数但解锁，V0.10保留锁定状态。旧草案内凹过深无法容纳默认厚度时，左右厚度回退为0。无效文件不改动当前草案。
- 原本地草案的参数保留，但旧版本锁定状态不视为对新侧墙规则的确认。
- 导出SVG只有轮廓路径，保留毫米物理单位，不包含尺寸线或内部图案。12导出两片独立路径，连接区为空白，不包含未经确认的铰链。
- 3D由同一份参数生成封闭凸多面体。前墙沿+Z、后墙沿-Z、左墙沿+X、右墙沿-X、屋顶沿各自坡面向外法线加厚。基准侧墙上沿Y=Hs贴合屋顶底面；屋顶前后端分别延伸到D/2+(H+R)sinA+前厚cosA+E、-D/2-(H+R)sinA-后厚cosA-E。G仅用于展开图，不生成铰链实体。 左右坡面法线为(±R/S, W/(2S), 0)，总高为H+R+屋顶厚度×W/(2S)。折叠脊部保留两个矩形厚板的端面，不自动斜切或填补法向加厚后的脊部空隙。 左右檐口X=±(W/2+L)，Y=H-2RL/W，坡度和原有墙顶交点保持不变。左右外延过大使檐口低于底面时显示警告。

## 确认流程

V0.10：左右侧墙在外倾时补入前后三角翼片，0°仍为矩形，非零角度为六边形。每端外伸为Hs·sinA，补片肩部高度为Hs·cosA，总宽D+2Hs·sinA，底边D不变。补片斜边满足Z=±(D/2+Y·tanA)，与倾斜墙内侧平面对应；上方核心墙高仍为Hs，屋顶高度接缝未自动修正。SVG虚线标出原矩形边界，导出轮廓包含补片。旧规格参数保留并解锁，新版本重新推导侧墙。

点击SVG徽章或3D实体面选择1、3、6、9、12，左栏仅显示对应面参数与派生尺寸。左右屋顶统一选择12，拖动旋转不触发选择。页签支持键盘切换；导出轮廓默认同步当前面。倾斜后屋顶前后基准进深由尖顶外移和墙厚水平投影推导，前后外延继续加在该基准之外。

外倾基准具体取右侧墙下角与前后山墙内侧的接点：(W/2-I,0,±D/2)。3D以红点标出，旋转轴为经过该点的X方向横轴；该轴与之前的底边基准线共线，修正基准描述而不改变既有倾斜结果。组合模式显示红点，分解模式隐藏，规格导出包含基准点坐标。

前后墙底部基准顶点不动，分别朝+Z/-Z向外倾斜：原墙内点(x,y,z)变为(x,y·cosA,z±y·sinA)。厚度方向同步变为(0,-sinA,±cosA)，保持实际法向板厚不变。实际板材SVG轮廓不随装配角度变化；竖直投影高为(H+R)cosA，尖顶外移为(H+R)sinA。屋顶进深跟随倾斜尖顶，但屋顶高度暂不联动，侧墙三角补片随倾角变化，非零角度显示接缝警告与旧位置虚线，不冒充闭合装配。底部基准线固定，但加厚后的外侧下缘会低于基准底面，后续需讨论倒角。旧的共面收窄红色三角区在倾斜时不再适用，隐藏该诊断。

I改变侧墙装配位置及其高度，山墙和屋顶轮廓不变。左右侧墙位于X=±(W/2-I)，侧墙间距为W-2I，侧墙高度Hs=H+2RI/W。I允许0到70毫米，且左右厚度之和必须小于W-2I，内部净宽为W-2I-左厚-右厚。SVG红色竖线由底部一直延伸至斜屋顶交点，I尺寸线从山墙最外沿水平量起。I<T时仍存在山墙下部三角接缝；不自动修改山墙轮廓。

先在页面讨论宽、高、尖顶和进深，再确认是否收窄、连接区宽度。参数确认后导出规格，形成项目内的批准版本，再让方案2和5的内部设计适配同一母版。

## V0.12 五层纸板底座（当前规则）

底座改为五层完全相同、同厚度的纸板，单层参数为`baseLayerThickness`，总厚为该值乘5。五层从房屋实体最低Y值向上叠合，不再有独立实心承托底板；每层贯穿开孔相同，沿用整体下插路径投影生成插槽。展开时共用分解间距，四个下层依次向下拉开，最上层保留原位置；合拢时连续贴合。SVG导出一张单层裁切模板，需要裁切5份。封闭环形槽中央的纸板区域是独立片，实际装配需要一并叠放固定，尚未添加连接桥或胶粘结构。

V0.12规格记录材料、5层、单层厚度、总厚度和贯穿槽类型。旧版底座总厚`baseThickness + baseFloor`除以5迁移为单层厚度，旧版草案解锁。旧的两个厚度字段仅为兼容旧规格保留，不参与当前几何或显示。最底层底面改为房屋最低点基准。

以下V0.11说明仅为历史记录，底板和盲槽规则已被V0.12替代。

## V0.11 矩形底座（历史）

- 点击底座或左栏底座页签，调整左右宽度、前后长度、向上厚度、承托底板厚度、插槽单边间隙。默认100 × 80 mm，向上4 mm，底板1.5 mm，单边间隙0.25 mm。
- 底座基准是全部房屋实体的最低Y值，而非倾斜前的Y=0；前后墙向外加厚后下缘可能略低于0。顶面为基准加向上厚度；底面为基准减承托底板厚度，总厚度为两项之和。
- 使用本地JSCAD Modeling 2.12.1布尔运算。每个非零厚度面板截取顶面以下部分，并将其凸投影沿竖直方向开槽，再按单边间隙扩张。相比仅减去最终重合部分，插槽略宽，但无倾斜倒扣，覆盖整屋竖直下插路径。
- 槽下保留完整底板，使内部区域与外框连成一个实体。没有自动圆角或加工拔模角。外沿不足2 mm或面板厚度为0时显示警告；尺寸过小的底座不能保证承托完整房屋，需调整长宽。
- 3D包含独立底座实体选择、房子和底座开关、整屋竖直抬升的下插预览。面板分解与整屋抬升是不同预览操作。
- 导出JSON包含底座参数、基准与插槽类型；底座SVG仅为顶面盲槽轮廓，不代表贯穿切割。默认间隙只是试制起点，未验证实际生产公差或插接强度。
- V0.11保留当前锁定状态，V0.1到V0.10保留已有参数、补充底座参数并解锁，不覆盖用户已有尺寸。离线HTML直接使用本地库，不依赖CDN。

验证：`node --test tests/badge-dimensions.test.cjs tests/badge-base.test.cjs`。覆盖实体布尔差集、完整承托底板、0°/20°/45°多个下插高度的无实体干涉以及旧规格迁移。
