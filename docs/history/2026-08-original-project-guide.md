# AWS User Group 社区勋章项目 · 核心规范与多 Agent 协作指南
> **文档定位**：本项目由多台设备上的多个 Agent（智能体/AI 助手）协同维护与执行。本文档为**主上下文交接手册（Master Onboarding Guide）**，任何新介入的 Agent 请务必完整阅读本指南后再开展后续工作。

---

## 1. 项目核心背景与目标 (Project Overview)

* **项目名称**：AWS User Group (UG) 社区内部激励成就勋章设计与生产交付。
* **激励对象**：社区贡献者（包含 Leader 领袖、Speaker 讲师、Volunteer 志愿者）。
* **激励规则**：按连续组织/参与月度发放（**1、3、6、9、12 个月**），其中 12 个月勋章获取难度极高（约 30:1 悬殊比例）。
* **🎯【核心铁律】最终产出物定义**：
  * **本项目的唯一最终核心产出物就是 AI 生成的 16:9 纯平面工程对比设计大图**。
  * **任何针对设计、提示词或开模规则的修改，最终必须落实为新生成的实物工程对比图交付给用户审阅**，严禁仅做文字/关键词修改而无图纸视觉交付。
* **最终交付标准**：符合**硬珐琅（Hard Enamel）工艺标准**的 **纯平面 2D 矢量工程图纸（Flat 2D Technical Vector Blueprint）**，用于直接对接工厂开模制作实物。

## 2. 核心设计哲学与不可变更红线 (Design Rules & Red Lines)

本设计为**基于官方参考图的传承与优化**，严禁随意推倒重来，必须严格遵循以下原则：

### (1) 两大核心文化交织
1. **社区家庭文化（根基母体）**：必须使用**小房子（House Silhouette）**作为不可动摇的核心轮廓，象征 AWS User Group 是所有开发者温暖、包容、共同成长的大家庭。
2. **开发者创意文化（进阶灵魂）**：以**点子（The Spark / Idea）从萌芽到向外发散爆发**作为勋章进阶的唯一灵魂，彻底取代传统陈旧的月桂叶、翅膀羽毛、星星月亮、传统皇冠等元素。

### (2) 绝对不可变更的母体要素（Red Lines）
* **小房子外形与比例**：标准尺寸宽 28.0mm × 高 34.0mm，坡屋顶角度与下半部切角固定。
* **文字与 Logo 标准排版**：
  * 顶部：官方 `aws` Logo（含微笑箭头）。
  * 中部：角色专属图标（橙色旗帜 / 紫色麦克风 / 绿色双手托心）+ 加粗大写文字（`UG LEADER` / `UG SPEAKER` / `UG VOLUNTEER`）。
  * 底部：弧形纯色硬珐琅色块底座 + 金色数字与周期标注（如 `1` + `MONTH` 或 `12` + `MONTHS COMBO`）。
* **同源一致性原则**：**1 Month 与 12 Months 的小房子内部文字、Logo、图标与色块底座必须 100% 绝对同源一致**。12 Month 的进阶**仅在小房子背后向外进行发散扩展**，内部骨架严禁发生任何位移、变形或改动！

### (3) 单一元素纯粹性原则（严禁元素杂交）
* 每一个方案只能贯彻**单一、纯粹的图腾发散逻辑**（例如：方案 A 纯几何粗折块射线、方案 B 纯加粗电路母线载板、方案 C 纯模块六边形实心积木）。
* **严禁在一个方案中混杂多种不同逻辑的元素**（如严禁出现“光芒 + 月桂叶”、“电路 + 羽翼”等杂乱拼凑）。

### (4) 实物开模与量产可行性红线（Physical Manufacturability - 必读必守）
勋章将采用市面主流的**仿珐琅 / 锌合金烤漆（Imitation Hard Enamel / Die-Cast Zinc Alloy）**工艺制作，必须严格遵循以下制造红线：
* **🚫 绝对严禁任何透光镂空（Zero Cutouts / 100% Solid Backing）**：
  * 整个勋章必须为**完整的实心金属底板与实心填色色块**，严禁出现任何镂空孔洞、网眼透光或镂空缝隙（镂空会导致冲孔模具成本暴增、抛光漏色且极易卡垢断裂）。
* **🧱 现代大体量与加粗金属线条（Chunky Bold Lines & Broad Color Blocks）**：
  * 勋章主体具有强烈的现代大色块与厚重体量感，外围扩展**严禁使用细碎插画式的“细密发丝线/极繁乱线”**！
  * 必须采用**加粗的金色金属凸棱（Raised Metal Ridges ≥ 0.8mm~1.5mm）**与**大面积平整实心珐琅填色块（Broad Flat Enamel Blocks）**，形成厚重、稳健、现代的视觉张力。
* **🛡️ 一体化连续外轮廓与安全钝化（Contiguous Silhouette & Safe Chamfers）**：
  * 外轮廓所有尖角一律做微倒角钝化，杜绝刺针锐刺，确保佩戴安全不勾衣物。
  * 严禁出现孤立悬空断线、悬空浮点或薄片状单点连接。

## 3. 视觉阶梯体系与色卡标准 (Tiers & Colors)

### (1) 1 到 12 个月成长阶梯规划（1月必须体现主题雏形）
* **1 Month（启程微光）**：保持小房子标准主体（宽 28mm × 高 34mm），**但在屋顶或边缘必须巧妙融入 1~2 个加粗极简的主题体块雏形**（如方案 A 的 1 个粗折角几何光棱、方案 B 的 1 组加粗电路芯片母线端子、方案 C 的 1 个互锁实心六边形积木），为进阶埋下伏笔。
* **3 Months Combo（起步微光）**：屋顶向上探出 3 组粗体量发散块面。
* **6 Months Combo（中坚共鸣）**：屋顶与两侧展开 6 组立体折面实心大色块。
* **9 Months Combo（专家星冕）**：背部展开 9 组多维实心科技护甲体块。
* **12 Months Combo（巅峰灯塔）**：**如宏大厚重星甲般全方位展开的实心无镂空大体量爆发**（总外径展宽至 44mm~58mm，实心大色块与加粗镀金母线），极致体量感与视觉张力，匹配 30:1 的王者稀有度。

### (2) 三大角色配色规范 (Hard Enamel Pantone Codes)
* 🟧 **UG LEADER**：AWS 活力橙（Pantone 151 C）+ 象牙白（Pantone 7499 C）+ 小旗帜图标（Flag）。
* 🟪 **UG SPEAKER**：科技深紫（Pantone 2685 C）+ 象牙白（Pantone 7499 C）+ 麦克风图标（Microphone）。
* 🟩 **UG VOLUNTEER**：极客绿（Pantone 368 C）+ 象牙白（Pantone 7499 C）+ 双手托心图标（Heart & Hands）。
* 🟡 **金属电镀**：高光 24K 金色电镀（Polished Raised Gold Plating），主线条线宽 ≥ 0.35mm，外圈结构连接筋宽 ≥ 0.8mm。

## 4. 工程目录组织与归档规范 (Directory Architecture)

为保证多 Agent 在不同电脑上协作时不发生文件冲突与混乱，**必须严格执行独立文件夹归档规范**：

```text
pin/
├── README.md                              <-- 整个项目的导航与方案索引
├── 项目核心规范与Agent协作指南.md           <-- 【当前文档】多 Agent 协作的主纲领
├── 参考图/                                <-- 官方原始设计素材与历史图纸
├── 方案A_纯几何棱镜光芒/                    <-- 方案 A 独立包
│   ├── 方案说明.md                         <-- 包含设计理念、尺寸工艺、生图 Prompt
│   └── 1月与12月纯几何光芒对比设计图.jpg      <-- 16:9 纯平面同源对比工程大图
├── 方案B_极客电路矩阵光冕/                  <-- 方案 B 独立包
│   ├── 方案说明.md
│   └── 1月与12月电路矩阵光冕对比设计图.jpg    <-- 16:9 纯平面同源对比工程大图
└── 方案C_模块六边形集群/                    <-- 方案 C 独立包
    └── 方案说明.md
```

> ⚠️ **协作红线**：严禁在 `pin` 根目录下直接乱扔图片或零散 md 文件，每一个新方案必须独立建文件夹，实现**文档 + 图片自闭环**。

## 5. AI 生图与工程图纸生成标准 (AI Prompt & Blueprint SOP)

为保证出图符合工厂工程制版需求与实物制造可行性，执行以下 SOP：

1. **必须为 16:9 纯平面正视矢量图（Flat 2D Vector Blueprint）**：
   * 严禁生成带有倾斜角度、3D 真实摄影、布料背景、阴影杂乱的效果图。
   * 采用纯色中性灰背景（Slate Grey），清晰呈现金色金属线条与平整珐琅填色。
2. **必须采用“16:9 单画布并排成对出图”**：
   * **左侧固定**：`1 MONTH` 基础款（无外发散）。
   * **右侧固定**：`12 MONTHS COMBO` 巅峰款（完全相同母体 + 实体一体化背部发散）。
   * 同画布生成确保两者的光泽、字体大小、比例绝对一致，并使生图调用次数减少 50%。
3. **必须强制约束实物开模一体化轮廓（Manufacturability Prompting）**：
   * Prompt 中必须包含 `unified contiguous outer silhouette`, `solid single-piece die-cast metal framework`, `interconnected solid structures`, `no floating isolated lines, no fragile disconnected spikes` 等约束词。

### 标准 Prompt 核心结构模板：
```text
Flat 2D technical vector blueprint comparison on a solid neutral slate grey background, 16:9 wide aspect ratio. Side-by-side design comparison of two AWS User Group lapel pins with identical central house-shield proportions and identical typography. LEFT PIN: '1 MONTH' base pin, featuring a clean house-shield silhouette, ivory enamel top with official 'aws' logo, [ROLE ICON], '[ROLE TEXT]' text, and bottom [COLOR] enamel block with '1' and 'MONTH', perfectly clean without outer beams. RIGHT PIN: '12 MONTHS COMBO' master pin, possessing the EXACT IDENTICAL central house-shield body and text as the left pin (with '12' and 'MONTHS COMBO'), but radiating outward from behind the house is a pure [SPECIFIC CORE MOTIF ONLY] integrated into a unified contiguous solid metal outer frame (strictly NO leaves, NO laurels, NO organic feathers; strictly NO floating isolated lines, NO disconnected fragile spikes, NO floating dots; robust single-piece die-cast lapel pin manufacturing standard with smooth wearable outer perimeter). Technical orthographic 2D vector artwork, sharp gold metal lines, flat enamel color fills, professional side-by-side factory specification layout. --ar 16:9
```

## 6. 新 Agent 接手后的标准工作流 (Handover Checklist)

当有新 Agent 接入接力时，请按以下 4 步执行：
1. **第一步（对齐上下文）**：阅读本文档与根目录 [README.md](./README.md)，确认已有方案 A、方案 B、方案 C 的进展。
2. **第二步（明确任务目标）**：如果是探索新方案，选定**唯一的极客/开发者核心图腾**，并在本地创建独立文件夹（如 `方案D_XXX/`）。
3. **第三步（执行标准出图）**：使用上述 16:9 标准模板生成左 1 月右 12 月的纯平面工程对比图，图片直接落盘至对应方案文件夹中。
4. **第四步（闭环文档）**：在方案文件夹内编写 `方案说明.md`，并在根目录 `README.md` 中添加对应方案的索引与链接。
