## 打样前需补齐

|工作项|当前状态|交付或待确认结果|
|---|---|---|
|六面外轮廓与尺寸|已有 V0.12|供厂方核对可行性；不得依图片重新描外边界|
|内场矢量、字标及吉祥物|位图视觉已选，工程矢量未定|可编辑路径、文字处理、正反面与朝向标注；核对字标使用规范|
|材料与表面处理|未确定制造规格|由工厂提供候选与限制，负责人选定|
|配色 / 分区|有视觉参考，无实体色样批准|实物色样或可追溯色号、分区标识与批准记录|
|浮雕 / 凹刻 / 银框|目前是图片效果|剖面与高度深度、最小线宽和字形可读性，厂方反馈后确认|
|背面与佩戴结构|待确认|背面图、固定方式、重量及安全边缘要求|
|屋顶连接与墙面拼装|名义组合已有|连接方式、接缝、斜切、倒角及实际装配可行性|
|公差与配合|未获工厂验证|测量基准、关键配合、公差及允许调整范围|
|纸板底座|五层名义尺寸已有|独立内片如何固定、材料与层间结合、实物强度|
|成本 / 工期 / 样品数量|尚无记录|工厂报价、打样周期、数量和修改费用说明|

AI 图的阴影不能直接解释为真实槽深；固定边界的嵌图 SVG 也不等于内场已经矢量化。当前约 8.2 mm 吉祥物主体的视觉尺度不代表其细节已通过制造验证。上述待定值不得凭经验填入“已批准”栏。

## 执行顺序

1. 负责人确定首次打样范围：分支、角色配色、板件、底座、数量及是否需要完整装配样。
2. 准备六面版本清单、批准外轮廓、工程矢量与待确认问题；给文件明确版本和“打样评审，非量产批准”标记。
3. 工厂回传材料 / 工艺建议、可行性反馈、结构图、公差、报价与工期，逐项留存回复。
4. 若工厂建议改几何，记录理由及影响，先获得负责人确认，再建立新工程版本；不覆盖 V0.12。
5. 确认打样图纸与样品范围后再下单。本项目目前未完成这些确认，不主动代下单。
6. 收样后按下表测量、拍照与试装，记录问题和返修要求。样品通过后单独评审生产批准。

## 样品验收

|检查项|需要记录的证据|
|---|---|
|版本与数量|样品编号、对应图纸 / 配色版本、到样日期及工厂|
|单枚尺寸|六个板面的宽高厚度、关键开口 / 插槽及测量位置|
|外观|正反面与边缘清晰照片；银框均匀度、色差、污点、毛刺和文字可读性|
|金属 12 专项|饰条高光 / 阴影及表面均匀度；固定光照下比较，不只看渲染图|
|拼合|六面朝向、屋顶折叠 / 连接、接缝、下插及拆装过程照片或视频|
|底座|五层对齐、独立内片固定、稳定性及实物配合|
|佩戴与安全|背面固定可靠性、触边检查；其他测试项目与验收条件先约定|
|结论|通过 / 返修 / 待确认，问题负责人、处理方案与用户确认日期|

本清单没有擅自设定合格阈值、量产测试标准或寿命指标；这些应在下单前与工厂、负责人约定。首次样品合格也不自动覆盖所有分支和配色。

## 文件与记录规则

实际启动时再建立 `specs/sampling/YYYY-MM-DD-厂方或批次/`，建议包含版本清单、发厂工程文件、厂方反馈、报价、样品照片、测量表和验收记录。当前尚无实际批次，不能创建虚假的报价或验收结果。

一两版可选探索放到独立日期化设计目录，注明“候选，未替换当前选定版”。不得让可选探索掩盖打样主线或默认增加工厂范围。

量产批准必须有明确工程版本、工艺与样品确认。只有获得相应授权后，才考虑更新 `productionReady`；本次不改 JSON。
